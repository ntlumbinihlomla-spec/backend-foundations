# Revanant offer: business reporting and workflow automation

Backend Foundations is the broader custom-work and reporting offer in the Revanant portfolio. It remains a separate Python toolkit and application; Sentinel and Aegis are separate projects and are not runtime dependencies.

## Buyer and problem

Start with bookkeepers, small accounting practices, and SMEs that repeatedly turn CSV exports into owner or client reports. The first conversation should identify one recurring report and its current manual steps, not sell every feature in the repository.

## First offer: CSV Report Pilot

**Outcome:** turn one agreed CSV export into an understandable dashboard and client-ready report.

**Proposed scope:**

- One input format and one agreed numeric field or set of metrics.
- CSV upload or a public CSV source where appropriate.
- Summary and batch comparison available in the existing demo flow.
- One report/export and one handover walkthrough.
- A written acceptance check against a sanitized sample.

**Exclude unless separately scoped:** accounting-system or bank integrations, tax advice, bespoke forecasting, multi-tenant security guarantees, ongoing hosting, and unlimited data cleanup.

The current planning docs suggest R3,500 for a direct pilot and R299/month for access, and a Fiverr tier structure of $35/$95/$180. Treat these figures as unvalidated starting hypotheses. Confirm effort, third-party costs, support burden, platform fees, and buyer willingness before quoting.

## Delivery checklist

1. Ask what decision the report supports and how often it repeats.
2. Agree on a sanitized sample and the fields to include or exclude.
3. Write scope, price, timeline, deposit, acceptance check, revision limit, and data retention in one short proposal.
4. Demonstrate using sample data before importing client data.
5. Deliver the report, supported files, and simple operating instructions.
6. Ask whether the same report recurs and record the actual time saved before proposing ongoing service.

## Demo narrative

1. Start with a fictional CSV export.
2. Upload or select the sample, choose the agreed field, and show the resulting summary.
3. Show how a batch of files contributes to the report.
4. Export the client-facing report.
5. State clearly what the demo does not cover: live accounting connections, tax conclusions, or guaranteed error-free interpretation of every CSV.

## Portfolio cross-reference

- **Sentinel** is the small, read-only CLI offer for validating and summarizing CSV batches.
- **Backend Foundations** is the custom dashboard/reporting offer for a client-specific workflow.
- **Aegis** is a separate developer-facing read-only repository scan.

Cross-reference the sibling projects as portfolio examples only. Do not couple their code, share client data between them, or imply that buying one includes another.

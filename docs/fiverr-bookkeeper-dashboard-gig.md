## Description

Are you a bookkeeper or accountant still chasing clients through email, spreadsheets, and manual reminders?

I will build a simple client dashboard that helps you see:

- overdue invoices
- outstanding invoice totals
- missing receipts or documents
- clients and suppliers
- daily attention items
- exportable reports
- basic bank CSV import and matching

This is not a full accounting system. It is a lightweight dashboard for the painful follow-up work that bookkeepers and accountants deal with every week.

Best for:

- small bookkeeping firms
- solo accountants
- SME finance/admin teams
- consultants who manage client records

What I need from you:

1. A sanitized spreadsheet or CSV.
2. The workflow you currently manage manually.
3. The things you chase clients for.
4. The report or dashboard you want to see every morning.

I can also use demo data first if you want to see the structure before sharing sanitized records.

## FAQ

### Is this a full accounting system?

No. It is a focused dashboard for tracking client follow-ups, overdue invoices, missing documents, and simple reports.

### Can you work with Xero or QuickBooks?

For the first version, I work from sanitized CSV/spreadsheet exports. API integrations can be added later as a custom order.

### Can you use my real client data?

Please remove private client details first. Use sanitized data for the pilot.

### Can you host it?

Yes, hosting can be included in the Premium package or quoted as a custom monthly support add-on.

### Can you customize it for my firm?

Yes. I can adjust fields, labels, dashboard sections, and reports around your workflow.

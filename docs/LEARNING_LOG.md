## 2026-06-04

### Lesson 1: What This Project Is

This project is a lightweight client dashboard for bookkeepers and accountants.

It is meant to show:

- who owes money
- what is overdue
- what receipts or documents are missing
- what needs attention today

The first version is not a full accounting system. It is a focused dashboard for client follow-up work.

### Words Learned

- Frontend: what the user sees and clicks
- Backend: the engine that stores data and handles actions
- Database: where records are saved
- API: the way the frontend talks to the backend
- CRUD: create, read, update, delete
- Authentication: proving who the user is
- Authorization: deciding what the user may access

## 2026-06-04

### Lesson 2: Legacy Toolkit And CLI

The pasted "Backend Dev Legacy Toolkit" idea says serious backend wealth usually comes from owning infrastructure around:

- money
- time
- trust
- decisions

For this project, the best path is not to abandon the bookkeeper dashboard. The best path is to use it as the starting point.

Path:

```text
Bookkeeper dashboard -> client workflow system -> audit-safe financial operations toolkit
```

CLI means Command Line Interface.

A CLI lets you control software by typing commands in a terminal.

Example:

```bash
python tools/generate_bookkeeper_evidence.py
```

That command generates proof files for outreach.

### Words Learned

- CLI: command line interface
- Infrastructure: important software layer other systems rely on
- Audit trail: record of who did what and when
- Workflow: steps in a business process
- Primitive: a basic building block, such as invoices, ledger entries, tasks, or audit logs

## Gig Description

Paste this:

Do you have CSV or spreadsheet exports that your team reviews manually every month?

I will build a simple financial CSV dashboard that turns your file into clean summary metrics, batch analytics, and a client-ready report.

This is ideal for:

- Small businesses
- Bookkeepers
- Finance consultants
- Founders and operators
- Teams that export sales, expenses, revenue, or transaction data

What I can build:

- CSV upload dashboard
- Summary cards for totals, averages, min/max, and rows
- Batch analytics across multiple CSV files
- Contribution bars to compare files
- Exportable HTML report that can be printed or saved as PDF
- Basic branding for your business

Please message me before ordering if your CSV has unusual formatting, multiple sheets, sensitive data, or needs a custom calculation.

Important:

This Gig does not include bank connections, accounting system integrations, complex forecasting, or full enterprise security. It is a focused dashboard/reporting pilot for CSV-based workflows.

## Fiverr FAQ

Question: Can you work with Excel files?

Answer: This Gig is focused on CSV files. If you have Excel files, message me first and I can confirm whether they should be exported to CSV or quoted as a custom job.

Question: Can you deploy the dashboard?

Answer: Yes, deployment is included in the Premium package. For Basic and Standard, deployment can be added as a custom extra.

Question: Can you make the report match my brand?

Answer: Yes. Standard includes basic branding. Premium includes a more polished branded demo and report.

Question: Is my data safe?

Answer: Please send a sanitized sample file before ordering. Do not send live financial or personal data unless we have agreed on the handling requirements first.

Question: Can you connect to QuickBooks, Xero, bank accounts, or payment processors?

Answer: Not in this Gig. This Gig is for CSV-based dashboards. Integrations can be discussed as a separate custom project.

Question: What do you need from me?

Answer: I need a sample CSV, the column you want summarized, your preferred labels, and any branding details.

## Buyer Requirements

Add these as structured Gig requirements:

1. Upload a sample CSV file. A sanitized sample is preferred.
2. Which numeric column should be summarized? Example: `amount`, `revenue`, `sales`, or `total`.
3. What should the report title be?
4. What business name or brand name should appear in the dashboard/report?
5. Do you need batch comparison across multiple files?
6. Do you need deployment, or only the dashboard/report files?
7. Are there any calculations or columns that must be excluded?
8. Confirm that you have removed sensitive personal or financial data from the sample file.
